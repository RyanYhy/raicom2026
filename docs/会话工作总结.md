## 1. 项目概况

- **比赛**：RAICOM 2026 全域安防 · 智能侦察赛道，现场 5 分钟。
- **设备**：Mecanum 全向底盘，ROS Melodic（仅 `/opt/ros/melodic`），x86 7.5GB RAM。
- **推理环境**：`yolov8` conda 环境（py3.8.20）是唯一有 onnxruntime 1.19.2 的地方；节点**不得**在运行时 import torch/ultralytics。
- **双相机**：
  - 板载 Webcam `/dev/video0`（Realtek `0bda:3031`）—— **MJPG 848×480 唯一稳定**，640×480 必失败；装在云台上带水枪。
  - Orbbec DaBai DCW2（`2bc5:0561` 彩色 / `2bc5:06a0` 深度）—— 只能走 SDK；640×480 彩色 @10-15fps + 深度 640×400（0-1m 有效）；装车头固定。
- **云台水枪**：`/dev/gun`→ttyUSB2 @115200，协议 `AA BB 01/02 <angle> 0D 0A`，开火 `AA BB 03 01/00 0D 0A`；**0.05s 点射有效、冷却 3s**；pan 0-180（中 90）、tilt 70-110（中 90）。
- **底盘**：`/dev/carserial`→ttyUSB0 @115200，协议 `AA BB 0A 12`，AMCL `odom_model_type="omni"`。

## 4. 关键技术结论与坑（务必记住）

### 4.1 相机
| 项 | 结论 |
|---|---|
| Webcam 分辨率 | **848×480 MJPG 稳定**；640×480 必失败（固件/链路），1280×720 也可用 |
| Webcam 打开 | **首次 `cap.read()` 偶发瞬时失败** → 必须热身 0.2s + 重试 3 次（已写入 collect.py） |
| Orbbec launch | **必须用 `dabai_dcw2.launch`**（DCW2 专用，`enable_color` 默认 true）；`dabai_dw.launch` 默认关彩色流，只出话题不出帧（日志 "Stream color is disabled"） |
| Orbbec 话题 | `/camera/color/image_raw` 640×480 MJPG；采集时关 depth/ir/点云省 USB2 带宽 |
| Orbbec USB 降速 | 12M 降级只能物理重插；健康检查：`lsusb` 见 2bc5 + `1-4.4.1` speed=480 |

### 4.2 软件坑
| 坑 | 解法 |
|---|---|
| cv_bridge 转换报 `PyInit_cv_bridge_boost` | cv_bridge 必须从 `/home/mowen/cv_bridge_ws/devel/lib/python3/dist-packages` 导入，且 **`sys.path.insert(0,...)` 提到最前**，否则解析到 melodic 的 python2 版 |
| 退出不清理、进程泄漏 | `rospy.init_node()` 会覆盖 SIGTERM/SIGINT（rospy/core.py:623），自定义清理信号必须在 rospy 初始化**之后**重新注册 |
| usb_cam 报 "Error while decoding frame" | 假警报，不影响发布的帧（已逐帧验证） |
| 舵机没归位 | 退出/异常时先归位再关串口（gimbal_server shutdown()） |

### 4.5 评审修复（8/10 评审闭环后的行为变化，务必记住）

| 项 | 行为 |
|---|---|
| **letterbox 反算** | `yolo_onnx.postprocess` 必须**先减半填充 (dw,dh) 再除 ratio**。旧代码乘 `(img_w/640, img_h/480)` 忽略 dw/dh → 848×480 竖直误差最大 104px。回归测试：新代码 0.00px 误差 |
| **s_v 默认 -1** | 代码默认 `S_V=-1.0`（`param/params.yaml` 同）。调高 tilt 指令角目标在画面**下移**→`s_v=-1`；填反=闭环发散永远打不中。ppd 标定不决定符号，二者都要标 |
| **计数跨档去重符号无关** | `cluster_person_detections` 用**像素位移连续性**合并两档同人（`|v2-v1|≈tilt_step×ppd_v`），s_v 填反也不双计数 |
| **安全门 0.50** | `choose_aim` 用 `danger_conf_min=0.50`（原 safe_conf_min=0.70）：友军/人质 conf≥0.50 且在 ±6°pan×±10°tilt 内 → SKIP_DANGER。不赌 -10 误伤 |
| **类别冲突需 pan∧tilt 双近** | 冲突判定 `|Δpan|≤6° AND |Δtilt|≤10°`（原只比 pan，会把同 pan 不同高度的真目标误删） |
| **干跑静态扫描** | `--dryrun` 且云台不可用 → `scan_static`（相机固定+像素去重计数），避免 10 个扫描位把同一人数 10 遍 |
| **帧序去重** | orbbec 10fps 而消费循环 30ms：`get_frame_seq()` 只处理新物理帧，否则"连续 N 帧确认"被单帧击穿 |
| **gimbal 关枪重试** | 关枪指令写失败 → 重试 3 次 + logfatal + 归位（否则水弹枪可能持续发射） |
| **ensure_master 先于 init** | `ensure_master()` 必须在 `rospy.init_node()` **之前**调用（无 master 时 init_node 直接抛异常，自动 roscore 是死代码） |
| **雷区红蓝同盘取高置信** | 每区最多 1 盘；红蓝同现（同盘双色误检）保留 **累加帧数 n 多** 的颜色（非单帧 conf，防某帧高 conf 误检压倒稳定多帧，评审#8），并保存证据图 `M_<区>_<色>_conf<conf>.jpg` |
| **模型加载 fail-fast** | 模型缺失/损坏 → logfatal + `sys.exit(1)`（不静默降级；相机块才允许降级） |
| **标定确认门 `calibrated`** | `param/params.yaml` 缺 `calibrated: true` → 禁开火（仅计数）。防止 ppd/s_v 未标定导致脱靶、a0/a1=0 无弹道补偿、枪口误指友军（评审#6）。标定完成并改 true 后重启 |
| **shutdown `_abort` 竞态** | SIGTERM 只中断主线程 spin，扫描跑在订阅回调线程。shutdown 先置 `_abort`，扫描/瞄准/开火循环据此立即退出，避免退出瞬间回调线程还在发 `/gun/fire`（评审#12） |
| **击倒验证位置门** | `_verify_knocked` 只认 `|Δu|<0.2×img_w 且 |Δv|<0.2×img_h` 内的 enemy 为"未倒"，防旁边第二个敌人干扰 |
| **rescan 并集限制** | 重扫后 `dets+dets2` 合并再聚类，极端下可能多报；按方案 §3.1.4 保留（聚类处理正常情形） |

### 4.6 视觉避障（8/10，子系统 C，取代 §4.2/4.3 旧 vision_obstacle）

| 结论 | 说明 |
|---|---|
| **点云发传感器帧 + 节点零 TF** | py3 下 tf2_ros/tf 不可用，节点不动态变换；`/visual_mine/obstacles` 发在 `camera_color_optical_frame`，由 costmap_2d C++ tf2 变换（与 laser scan 同构） |
| **球面点集免疫俯仰** | 每盘 Fibonacci 20 点 → 任一姿态 XY 投影≈半径圆盘，max_obstacle_height=0.4 不削减覆盖 |
| **每类独立 MineTracker** | min_hits=2 确认 / max_miss=8 丢弃 / 指数平滑 / stale 2s 清候选；静态盘对车移动鲁棒 |
| **双模型调度** | mine.onnx 每 tick，antitank.onnx 每 3 tick（`~at_infer_interval`，省 CPU） |
| **global+local 双注入** | `nav_competition_2026.launch` 自持 move_base（clear_params，无 ns），在 `<node>` 内**最后** load `visual_layer_params.yaml` 覆写 `observation_sources="scan visual_mine"`；roslaunch 按文档序写参数服务器 → 确定性生效，绕开 robot_bringup / robot_navigation 等底层包+clear_params 坑。**已 live 验证**两 costmap 均注入 |
| **observation_persistence=2.0** | 盘移走 ~2s obstacle 自然消失，不堵回程（obstacle_layer 先清本层再重标记） |
| **实测 cloud ≈4-5Hz** | mine.onnx 640×480 ~0.20s（threads=2；4 线程仅快 5% 不值）。静态盘+persistence+tracker 覆盖低帧率，可接受 |

### 4.7 航点重测实机流程（8/10 上机必做，用 competition_map）
