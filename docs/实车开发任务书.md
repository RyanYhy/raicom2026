## 1. 赛题理解（已与选手确认的最终版）

比赛模式 = **赛前准备 + 赛中执行**。

### 1.1 场地与赛道布局

地图 500×400cm 沙盘，划分为**四个依次通过的区域**（一区 → 二区 → 三区 → 四区），赛道含障碍区、直角弯、S 弯、U 形弯：

| 区域 | 任务点 | 任务 |
|---|---|---|
| 一区 | 识别打靶点 **A、B** | 人物识别（有敌则打靶） |
| 二区 | 雷区识别点 **A** | 红蓝地雷识别 |
| 三区 | 识别打靶点 **C、D** ＋ 雷区识别点 **B** | 人物识别（有敌则打靶）＋ 地雷识别 |
| 四区 | 纯通过区 | **反坦克盘视觉识别＋避障**（不停靠，无人物任务） |
| 终点 | — | 返回营地，车头冲线计时 |

### 1.2 三类任务

1. **人偶识别与打靶**：四个识别点 A/B/C/D 均"先识别、有敌才打靶"——识别敌军/友军/人质数量，识别到敌军才用云台水弹枪击倒，无敌军不射击。
2. **红蓝地雷识别**：二区雷区A、三区雷区B，识别红（未排雷）/蓝（已排雷）数量。
3. **反坦克盘识别与视觉避障**：反坦克盘为贴地低矮目标，**激光雷达扫不到**，必须用 Orbbec 深度相机检测并避障；**反坦克盘模型只在四区启用**（省 CPU）；全程不得碰撞。

### 1.3 输出要求

6 行侦察报告（**逐字精确**，多/少一个字符都可能扣分）：

```
A区发现x个敌军、x个友军和X个人质。   ← 全角顿号
B区发现x个敌军、x个友军和X个人质。
C区发现x个敌军、x个友军和X个人质。
D区发现x个敌军、x个友军和X个人质。
A雷区未排雷数量x个,已经排雷数量x个   ← 半角逗号
B雷区未排雷数量x个,已经排雷数量x个
```

同时必须保存**带标注框的证据图**（框+类别+置信度）。

### 1.4 硬性规则

- 现场测试 **5 分钟**，超时项目不计分；全程需要电脑录屏
- 禁止 rosbag 录制回放（发现=现场测试 0 分）
- 车体四轮完全进入雷区 = 直接判负
- 误击友军/人质扣分，碰反坦克盘扣分
- 总成绩 = 焊接 20% + 现场测试 60% + 技术报告 20%（报告 8/12 14:00 截止，已由另会完成）

## 2. 硬件与软件环境

| 项目 | 配置 |
|---|---|
| 底盘 | 麦克纳姆轮全向，串口 `/dev/carserial`（ttyUSB0 @115200，协议 `AA BB 0A 12`） |
| 激光雷达 | Lslidar N10_P，`/dev/lslidar`，前方 180°（屏蔽 90~270°），安装 5cm 高 |
| Webcam | `/dev/video0`，**只支持 MJPG，848×480 稳定（640×480 必失败）**，装在云台上 |
| Orbbec DaBai DCW2 | 车头固定，RGB 640×480 + 深度 640×400（0~1m 有效），只能走官方 SDK |
| 云台水弹枪 | `/dev/gun`（ttyUSB2 @115200），协议 `AA BB 01/02 <angle> 0D 0A`（pan/tilt）、`AA BB 03 01/00 0D 0A`（开火）；pan 0-180 中 90、tilt 70-110 中 90；0.05s 点射有效、冷却 1s |
| 计算平台 | x86 笔记本 7.5GB RAM，CPU-only；ROS Melodic；推理用 `yolov8` conda 环境（py3.8.20 + onnxruntime 1.19.2），**节点运行时禁止 import torch/ultralytics** |
| 模型 | person.onnx（{0:hostage,1:enemy,2:friend}，**必须确认是否已重训为 3 类**）、mine.onnx（{0:mine_red,1:mine_blue}）、antitank.onnx（{0:anti_tank}） |

```python

            rospy.Subscriber(ZONE_TOPIC, String, self._cb_zone, queue_size=5)
```

**改动④**：在 `_cb_info` 方法后新增两个方法：

```python
    def _cb_zone(self, msg):
        """nav 站名更新 (四区门控输入)。"""
        if msg.data != self._zone:
            self._zone = msg.data
            self._at_gate_state = None   # 强制重新记录门控切换日志

    def _at_enabled(self):
        """反坦克盘推理门控: 仅当当前站名在 at_gate_zones 内启用。
        at_gate_zones 为空 = 始终启用 (bench 独立运行)。"""
        if not self.at_gate_zones:
            return True
        on = self._zone in self.at_gate_zones
        if on != self._at_gate_state:
            self._at_gate_state = on
            if on:
                rospy.loginfo('[avoid] 进入反坦克盘检测区 (zone=%s), 启用 anti_tank 推理',
                              self._zone)
            else:
                rospy.loginfo('[avoid] 离开反坦克盘检测区 (zone=%s), 暂停 anti_tank 推理',
                              self._zone)
        return on
```

```python
        if self._tick % self.at_infer_interval == 0:
```

改为：

```python
        if self._at_enabled() and self._tick % self.at_infer_interval == 0:
```

## 7. 已知坑（历史踩坑记录，避免重踩）

1. **Cartographer 崩溃**：里程计时间戳启动瞬间重复 → 必须经 `odom_cleaner` 严格递增过滤（test/launch 内建图 launch（已归档） 已内置，别绕过）
2. **webcam 640×480 必失败**：只支持 MJPG 848×480（usb_cam_mjpeg.launch 已配置）
3. **USB 降速**：Orbbec 必须插指定 USB 口（`lsusb -t` 应 480M，12M 只能物理重插），udev 关 autosuspend
4. **roslaunch 参数打爆 argparse**：节点内用 `rospy.myargv(sys.argv)[1:]`
5. **srv 导入被遮蔽**：`from raicom2026.srv import ...` 时别 `sys.path.insert(0, ../src)`，用 devel 空间生成包（或调整顺序）
